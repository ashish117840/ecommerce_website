# 🍏 Fruits Bazar – PHP Ecommerce Website

A complete **PHP-based Ecommerce Website** built with **HTML, CSS, JavaScript, PHP & MySQL**.
This project includes **product listing, shopping cart, admin panel, order management**, and more.

---

## 📌 **Project Name**

**Fruits Bazar – Ecommerce Website in PHP**

---

## 📦 **Features of Fruits Bazar**

This PHP Ecommerce Website includes:

### 🛒 **Customer Features**

* Browse product catalog
* View product details
* Add to cart
* Checkout
* Track past orders
* User login & registration
* Search products
* Category-wise product filtering

### 🛠️ **Admin (Backend) Features**

* Admin login
* Add Category
* Add Products
* Edit/Remove Products
* Manage Orders
* View User Details
* View Customer Reviews
* Generate Reports (Daily/Weekly/Monthly)
* Dashboard overview

## 📥 **How to Install the Project?**

### **Step 1 – Download**

Download the project ZIP or clone from GitHub:

```bash
git clone https://github.com/ashish117840/ecommerce_website
```

### **Step 2 – Move to XAMPP Directory**

Copy the project folder and paste it into:

```
C:\xampp\htdocs\
```

### **Step 3 – Start Apache & MySQL**

Open XAMPP control panel → Start:

* Apache
* MySQL

---

## 🗄️ **How to Import the Database?**

### Step 1: Open phpMyAdmin

Go to:

```
http://localhost/phpmyadmin/
```

### Step 2: Create New Database

Create a new database (example):

```
fruits_bazar
```

### Step 3: Import SQL File

Click **Import → Choose SQL File → Upload**
File is located inside the project folder.

---

## ▶️ **How to Run the Project?**

Open browser and type:

```
http://localhost/ecommerce_website/
```

OR your folder name.
